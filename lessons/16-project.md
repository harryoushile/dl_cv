# 第 16 课：小项目

## 这一代要解决的问题

把前面的网络从「能跑通形状」推进到「能解释一次改动」。项目不再引入新结构，而是选定一个已有模型，训练、记录，并做一次有结论的修改。

## 知识要点

从下面三个里选一个作为起点：

- [code/lesson08_resnet.py](../code/lesson08_resnet.py) 的 `ResNet18CIFAR`
- [code/lesson11_mobilenet.py](../code/lesson11_mobilenet.py) 的 `MiniMobileNetV2`
- [code/lesson13_vit.py](../code/lesson13_vit.py) 的 `ViTTiny`

允许的一次改动包括：加上第 12 课的 SE、改变 stage 里的块数、改变通道宽度、使用 `--no-shortcut`。一次只改一件事，才能把准确率变化归因到这件事情上。

在这份教学配置、大约 30 个 epoch 时，ResNet-18 往往高于同轮数的 ViT-Tiny。具体数字以你自己的 [results.md](../results.md) 为准。

## 结构与形状表

沿用所选网络那一课的形状表。改动之后必须重跑形状检查，并把变化写进项目报告。例如加宽通道后，`Linear` 的输入维度要一起改。

报告里保留一张自己的形状表，至少包括：输入、第一次下采样之后、分类头之前、logits。

## 对应例程导读

不新增 `lesson16` 脚本。在所选文件上修改，或复制一份再改，避免把基线结果覆盖掉。训练命令仍然是：

```bash
python code/lesson08_resnet.py --mode shapes
python code/lesson08_resnet.py --mode train --epochs 30
```

把文件名换成你选的例程。

## 动手实验

提交这些内容：

1. 结构说明和一份手算形状表。
2. `--mode shapes` 的终端输出，指出它和手算表一致的三行。
3. 参数量、最好验证准确率、你记录下来的损失或准确率变化。
4. 一次改动：改了哪一个类或哪一个参数，准确率变高还是变低。
5. 大约 200 字：这次改动对应课程里哪一个结构想法。残差对应第 8 课，通道权重对应第 12 课，深度可分离对应第 11 课，patch 对应第 13 课。

## 思考题

1. 为什么一次实验只改一个因素？
2. 参数量增加而准确率下降时，你更怀疑是优化没训够，还是模型容量和数据不匹配？用什么对照实验区分？
3. 如果形状检查已经失败，为什么不应该开始 30 个 epoch 的训练？
