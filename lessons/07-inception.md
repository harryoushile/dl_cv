# 第 7 课：GoogLeNet 与 Inception

## 这一代要解决的问题

同一层里该用 1×1、3×3 还是 5×5。Inception 把它们并联，让网络自己用，并用 1×1 先降通道，避免 3×3 和 5×5 太贵。

## 知识要点

一个 Inception 模块四条支路，最后在通道维拼接：

```text
1x1 --------------------------->
1x1 -> 3x3 --------------------> concat
1x1 -> 5x5 -------------------->
3x3 pool -> 1x1 --------------->
```

1×1 的作用是先把通道降下来。输入 64 通道、3×3 想输出 32 通道时，直接 3×3 的乘法量和「先 1×1 降到 16，再 3×3」相比更大。课件不要求背公式，要求能指出降维发生在哪一条支路。

四条支路的高宽必须相同，否则 `torch.cat` 失败。所以 3×3 用 `padding=1`，5×5 用 `padding=2`，池化用 `stride=1, padding=1`。

完整 GoogLeNet 还有辅助分类器，帮助梯度传到浅层。下一课的残差更直接地处理「深层不好训」。本课把模块本身写清楚。

## 结构与形状表

输入 `(N, 3, 32, 32)`。

| 层 | 输出 |
| --- | --- |
| Conv 3→64，k=3，p=1 | `(N, 64, 32, 32)` |
| MaxPool | `(N, 64, 16, 16)` |
| Inception：32+48+16+16 | `(N, 112, 16, 16)` |
| Inception：48+64+24+16 | `(N, 152, 16, 16)` |
| MaxPool | `(N, 152, 8, 8)` |
| AdaptiveAvgPool + Linear | `(N, 10)` |

第一组通道是例程里 `Inception(64, 32, 32, 48, 8, 16, 16)` 的四条输出：1×1 得到 32，3×3 得到 48，5×5 得到 16，池化投影得到 16。
