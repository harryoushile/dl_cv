# 第 4 课：LeNet-5

## 这一代要解决的问题

1998 年的 LeNet 把「卷积提取特征、池化缩小、全连接分类」收成一条流水线，用来认手写数字。本课把这条流水线写完整。

## 知识要点

- 原版面向 32×32，激活用 tanh，池化用平均池化。MNIST 是 28×28，例程按 28×28 重算高宽，激活用 ReLU，以便和后面的网络对齐。平均池化保留，用来和第 3 课的最大池化对比。
- 第二层卷积的输入通道必须等于上一层的输出通道。这里是 6。
- 三次全连接把 256 维特征收到 10 类：256→120→84→10。

## 结构与形状表

输入 `(N, 1, 28, 28)`。

| 层 | 计算 | 输出 |
| --- | --- | --- |
| Conv 1→6，k=5 | (28-5)/1+1=24 | `(N, 6, 24, 24)` |
| AvgPool 2 | 12 | `(N, 6, 12, 12)` |
| Conv 6→16，k=5 | 8 | `(N, 16, 8, 8)` |
| AvgPool 2 | 4 | `(N, 16, 4, 4)` |
| Linear | 256→120→84→10 | `(N, 10)` |

`16 * 4 * 4 = 256`，这就是第一层全连接的 `in_features`。

## 对应例程导读

[code/lesson04_lenet.py](../code/lesson04_lenet.py) 的 `LeNet5`。

`self.features` 停在第二次池化，`self.classifier` 是三层全连接。`forward` 先走特征，再 `view` 拉直。形状日志的最后一行应是 `(2, 10)`。

原版 LeNet 的第一层是 6 个 5×5 核。例程没有使用 padding，所以高宽会按上表缩小。若随意加上 `padding=1`，256 这个数字就失效了。

## 动手实验

```bash
python code/lesson04_lenet.py
python code/lesson04_lenet.py --mode train --epochs 5
```

把 `AvgPool2d` 换成 `MaxPool2d`，高宽不变，再训练一次，把两次准确率都记到 [results.md](../results.md)。

## 思考题

1. 为什么第二层卷积不能把输入通道写成 1？
2. 平均池化和最大池化，谁更可能保留一个尖锐的亮点？
3. 如果输入改成原版的 32×32，拉直后的长度变成多少？
