# 第 15 课：U-Net

## 这一代要解决的问题

分类网络最后把空间压没了。分割要把每个像素分类，所以需要一条编码器把图变小，一条解码器把图变大，并用跳连把浅层细节接回来。

## 知识要点

- 编码器：两次卷积后最大池化，通道增加，高宽减半。
- 解码器：转置卷积把高宽加倍，再和编码器里同分辨率的特征在通道维拼接。
- 拼接之后通道数是两路之和，所以后面的 `DoubleConv` 输入通道要写成两者相加。例如 64 与 64 拼接后，下一层输入是 128。
- ResNet 的跳连是相加，DenseNet 的连接是拼接并且通道越来越多，U-Net 的跳连也是拼接，但是接在解码器对应的分辨率上，用来补回池化丢掉的边界。
- 本课没有医学数据集。训练数据是当场画出来的圆：圆内标签 1，圆外标签 0。输入图像就是这个圆的掩码，输出是每个像素两类的 logits。
- 检测只作阅读：分类是整张图一个类别，分割是每个像素一个类别，检测是若干个框加类别。两阶段方法先提议区域再分类，YOLO 一类的单阶段方法由网格直接预测框。检测的标注和损失足够单独开课，这里不写检测代码。

## 结构与形状表

输入 `(N, 1, 128, 128)`。

| 层 | 输出 |
| --- | --- |
| down1 | `(N, 32, 128, 128)` |
| pool + down2 | `(N, 64, 64, 64)` |
| pool + down3 | `(N, 128, 32, 32)` |
| 转置卷积 up2 | `(N, 64, 64, 64)` |
| 与 x2 拼接后 conv2 | `(N, 64, 64, 64)` |
| 转置卷积 up1 | `(N, 32, 128, 128)` |
| 与 x1 拼接后 conv1 | `(N, 32, 128, 128)` |
| 1×1 卷积 | `(N, 2, 128, 128)` |

最终形状固定检查为 `(2, 2, 128, 128)`：batch 2、两类、高宽回到 128。

## 对应例程导读

[code/lesson15_unet.py](../code/lesson15_unet.py)。

`UNet.forward` 把 `x1`、`x2` 留到后面拼接。`torch.cat([y, x2], dim=1)` 要求两路高宽已经相同。转置卷积使用 `kernel_size=2, stride=2`，正好把边长加倍。

`make_circle_batch` 生成图像和标签。`--mode train` 不走 CIFAR，而是用这批合成数据做若干步交叉熵，损失按像素计算。

## 动手实验

```bash
python code/lesson15_unet.py
python code/lesson15_unet.py --mode train --steps 50
```

确认形状行是 `output (2, 2, 128, 128)`。训练日志里的 pixel_acc 是这一小批圆上的像素准确率，用来看损失是否下降。把参数量填进 [results.md](../results.md)。

## 思考题

1. 为什么 `conv2` 的输入通道是 128，而 `up2` 只输出 64 通道？
2. 如果跳连改成相加，拼接前的两路通道数必须满足什么？
3. 分类头把空间收成 1×1，分割头为什么要把空间还原到输入大小？
